# Сквозной проект: Управления СТУДЕНТАМИ
## Лабораторная №1. Frontend
Создать интерфейс системы заявок без фреймворков. Обязательно использование
CSS-стилей. Бизнес-логика должны быть вынесена в отдельные файлы.  
### Основные страницы:
- Список студентов в формате таблицы. Таблица должна выводить основную
информацию о студенте, поддерживать основные операции с списком
студентов (добавление, редактирование, удаление, посмотреть подробную
информацию о студенте)  
- Форма добавления/редактирования с полями: ФИО студента, группа, ИСУ id,
номер общежития, комната, срок заселения, является ли студент иностранцем,
заметки. Обязательна базовая валидация полей формы (проверка на пустое
содержимое, проверка на числовое/строковое значение). При использовании
формы в режиме редактирования актуальные данные студента должны
автоматически подставляться в поля формы.  
- Досье на конкретного студента с выводом подробной информации о нем.  

### Обязательное требование к интерфейсу:
- Адаптивная верстка, минимальный дизайн  
- Интерфейс должен реагировать на действия пользователя и изменять
отображаемые данные согласно этим действиям  
- Логика валидации форм должна быть частично реализована через встроенные
атрибуты тегов, частично через JS-скрипт  
- Хранение информации о студентах в одной из структур в зависимости от
варианта: localStorage/cookies/indexDB  
- Добавить favicon (иконку вкладки браузера) в виде котика, который лучше всего
отражает ваш характер
